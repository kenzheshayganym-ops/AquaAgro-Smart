# AquaAgro Smart

Учебный прототип LLM-ассистента для оператора полива в Казахстане. Автор: Айганым Кенжеш, трек A. Агент отвечает на вопросы по искусственному снимку участков, вызывает инструменты Python и сохраняет диалоги в SQLite. Решение о поливе принимает человек.

## Быстрый запуск с Docker

Нужны Docker Desktop с Docker Compose, интернет, собственный оплачиваемый ключ OpenAI и пара ключей проекта Langfuse. Подписка ChatGPT не оплачивает OpenAI API. В `.env` укажите сервер того региона, где создали проект Langfuse.

1. Распакуйте архив и откройте терминал **в папке с compose.yaml**. Если получили проект через GitHub, сначала клонируйте репозиторий.
2. Скопируйте пример конфигурации:

   Windows PowerShell:
   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

   macOS/Linux:
   ```bash
   cp .env.example .env
   ```

3. Впишите в локальный `.env` значения `OPENAI_API_KEY`, `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`. `LANGFUSE_BASE_URL` должен совпадать с адресом сервера в настройках вашего проекта. Модель по умолчанию соответствует измеренной версии. Если она недоступна вашему ключу, измените `OPENAI_MODEL`; прежние метрики тогда не относятся к новой модели.
4. После подготовки `.env` запустите сервис одной командой:

   ```bash
   docker compose up --build
   ```

5. Откройте:
   - здоровье: http://localhost:8000/health
   - интерактивный API: http://localhost:8000/docs

При старте сервис проверяет конфигурацию, целостность снимка в SQLite, авторизацию Langfuse, отправляет тестовый трейс и **читает именно этот трейс** через `api.observations.get_many`. Отсутствие ошибки SDK не считается доказательством доставки. Если проверка не проходит, сервис не начинает принимать запросы. В журнале старта появится идентификатор подтверждённого тестового трейса. Проверка не вызывает OpenAI и не расходует токены модели.

Порт опубликован только на localhost. Это локальный сервис для учебной демонстрации, без авторизации пользователей. `user_id` задаёт метаданные и область памяти, но не подтверждает личность. Для публикации в интернете нужна отдельная авторизация, HTTPS и ограничение доступа. Не открывайте этот контейнер всему интернету.

## Первый вопрос

На `/docs` раскройте `POST /ask`, нажмите **Try it out**, вставьте:

```json
{
  "question": "Сколько воды использовано на A за 27–29 сентября 2026 включительно?",
  "user_id": "demo-operator",
  "session_id": "demo-session"
}
```

Нажмите **Execute**. Это реальный платный вызов модели. Эталонный расчёт: **400 м³**. Ответ может отличаться: модельные ошибки не скрываются и не исправляются вручную.

В результате есть `answer`, `trace_id`, `request_id`, `seconds`, токены и число вызовов модели/инструментов. Найдите `trace_id` в Langfuse, раскройте вызов `water_calculation` и следующие шаги модели. Трейс содержит пользователя, сессию, окружение, вариант и отпечатки данных. На трейс записывается оценка `format_valid`. Это проверка формата ответа, **а не оценка его фактической корректности**. Судья и правило с эталонами используются в ноутбуке при оценке и не вызываются автоматически для каждого пользовательского вопроса.

Можно также выполнить:

```bash
python scripts/check_service.py
```

Скрипт проверяет `/health` и отправляет один платный вопрос. Во время демонстрации не запускайте 40-примерные замеры повторно.

## Память и перезапуск

SQLite хранится в `/app/state/aquaagro.sqlite` на именованном Docker-томе `aquaagro_state`. Хранятся снимок, сообщения и записи учёта запросов. Агент читает последние **6 обменов** для пары `user_id + session_id`. Разные пользователи с одинаковым названием сессии не получают чужую историю.

Для проверки спросите про A, перезапустите контейнер и задайте уточнение в той же паре `user_id + session_id`. При перезапуске:

```bash
# Сервис должен быть запущен в другом терминале.
docker compose restart
```

Обычный `docker compose down` сохраняет том. **`docker compose down -v` удаляет данные**, используйте только для намеренного сброса. Локальные тесты проверяют сохранение сообщений при открытии базы новым экземпляром Store.

Один процесс Uvicorn обслуживает один вопрос агента одновременно. Если агент занят, `/ask` возвращает HTTP 429. Это защищает последовательность диалога в небольшом учебном сервисе, но не доказывает готовность к высокой нагрузке. `/health` проверяет доступность процесса и целостность базы; `tracing_startup_verified` относится к проверке при старте, а не к непрерывной доступности Langfuse.

## Структура

- `aquaagro/config.py` — конфигурация из окружения.
- `aquaagro/store.py` — SQLite, целостность снимка, диалоги, учёт запросов.
- `aquaagro/tools.py` — пять инструментов из измеренного ноутбука.
- `aquaagro/prompts.py` — исходный контракт и промпт агента.
- `aquaagro/agent.py` — LangChain-агент, вызовы и метаданные Langfuse.
- `aquaagro/tracing.py` — проверка авторизации и фактической доставки трейса.
- `aquaagro/api.py` — FastAPI: `/health`, `/ask`, `/docs`.
- `data/` — неизменные `snapshot.json`, `eval_set.json`, `manifest.json`.
- `notebooks/final_project.ipynb` — ноутбук с сохранёнными выводами, заполненным разделом 12 и исправленной повторной настройкой трекера.
- `reports/` — сводка последних измерений и границы локальной проверки.
- `tests/` — локальные проверки без платных ключей и внешних API.
- `Dockerfile`, `compose.yaml`, `.env.example` — запуск и конфигурация.

`.env` отсутствует в архиве и исключён из Git и Docker-контекста. В `.env.example` поля ключей пустые. Перед загрузкой файлов на GitHub не копируйте туда свой локальный `.env` или папку `state`.

## Данные и измерения

Авторские искусственные данные разрешены для использования и публикации в учебном проекте. Внешних документов и персональных данных в наборе нет. 8 участков, 13 показаний, 10 записей расхода воды и 3 события полива. Фиксированное время: `2026-09-30T12:00:00+05:00`.

Оценочный набор: **40** примеров, из них 24 типовых, 8 пограничных, 8 отказов. Эталоны заранее записаны по расчётам и учебным условиям. Инструменты агента не читают `eval_set.json`. Отпечаток вопросов: `25e867ba22c355da`. Полные отпечатки в `manifest.json`.

| Ступень | Правило | Судья | Средняя задержка |
| --- | --- | --- | --- |
| Базовый вызов | 15% (6/40) | 50% | 0,78 с |
| Промпт с контекстом и few-shot | 77,5% (31/40) | 72,5% | 0,87 с |
| Агент с инструментами | 92,5% (37/40) | 95% | 2,03 с |
| Агент с блокировкой давности | 95% (38/40) | 90% | 2,10 с |

Промпт против агента: точный двусторонний p = 0,109375. Агент против контроля давности: p = 1,0. Прирост последнего варианта не подтверждён. Служебная `compare_runs` преподавателя удваивает уже двустороннее p; в ноутбуке есть отдельный корректный расчёт, исходная функция сохранена.

Цена лучшего варианта: в среднем 2936,35 входных и 115,075 выходных токенов на вопрос, **$0,001359 / ответ и $1,36 / 1000** при тарифе $0,40 / $1,60 за миллион. Это оценка без скидки за кэширование, расходов судьи и хостинга. Источник тарифа: https://developers.openai.com/api/docs/models/gpt-4.1-mini .

Измерения относятся к ноутбуку, а не к повторной оценке упакованного API. При упаковке сохранены промпт и логика инструментов, включая известные ограничения. Добавлены конфигурация, постоянный том, API, разделение памяти по пользователям и метаданные окружения. Семантические ошибки агента не исправлялись после замеров.

Полные CSV из Colab не были переданы в исходном вложении. В архиве есть сохранённые выводы ноутбука и сводка, **но не выдуманные 40-строчные CSV каждого запуска**. Перед сдачей отдельно скачайте папку `aquaagro_data` из Colab и добавьте нужные CSV в `reports/`, исключив личную базу диалогов и любые секреты.

## Локальная проверка без Docker

Требуется Python 3.12. Создайте виртуальную среду:

```bash
python -m venv .venv
```

Windows PowerShell:
```powershell
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest -q
```

macOS/Linux:
```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Тесты проверяют инструменты, границы и давность, полноту данных, сохранение и изоляцию памяти, обнаружение изменения снимка, ошибки старта трекера, API и реальный граф LangChain с локальной тестовой моделью. Они не доказывают доступность внешних провайдеров и не измеряют качество настоящей модели.

Для запуска без Docker экспортируйте переменные из `.env` в окружение терминала, затем:
```bash
python -m uvicorn aquaagro.api:app --host 127.0.0.1 --port 8000 --workers 1
```

## Ограничения

Учебные пороги не являются агрономическими нормами. Влажность — относительный индекс, не измеренная объёмная влажность почвы. Возраст показаний считается относительно **фиксированного времени снимка**, а не текущего времени компьютера. ESP32 не подключён. Нет настоящих расходомеров, автоматического управления насосами, доказанной экономии воды или полевого испытания.

Не используйте ответы для самостоятельного управления оборудованием, точной нормы полива, подтверждения утечки или официальной отчётности. На неверные/неполные/устаревшие данные система должна обозначать ограничения. Известны ошибки границ и формата отказа даже при точности 95% на учебном наборе.

## Если запуск не удался

- Нет ключей: заполните три пустых поля `.env`.
- Langfuse не проходит проверку: проверьте, что оба ключа из одного проекта и адрес сервера соответствует региону. Чужие ключи не подходят.
- Трейс не прочитан: проверьте Langfuse Observations, доступ к интернету и повторите запуск. Для новых организаций используется API v2, без `trace.list`.
- OpenAI возвращает ошибку: проверьте баланс API и доступ к `OPENAI_MODEL`. `/health` не проверяет баланс OpenAI платным вызовом.
- HTTP 429 от сервиса: дождитесь окончания предыдущего вопроса.
- Порт 8000 занят: измените только левую часть привязки порта в compose.yaml.
- Снимок не совпадает с базой: не заменяйте измеренные данные. Для нового снимка используйте новый том либо намеренно удалите старый с пониманием потери диалогов.
