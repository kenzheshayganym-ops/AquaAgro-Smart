Предоставленная преподавателем compare_runs дополнительно умножает уже двустороннее значение binomtest на 2. Поэтому её вывод для 0 → 1 равен 0,0000008344650269, для 1 → 2 — 0,21875. Служебную функцию не изменять; отдельно приводить корректный двусторонний тест. p, показанное как 0,000000, не равно нулю.

Между агентом и вариантом с блокировкой давности изменился один ответ, p = 1,0: прирост качества не подтверждён.

## Ошибки и ограничение вывода об улучшении

Агент без блокировки дал -200 вместо 200 м³ в сравнении C и A, неверную категорию на равенстве влажности нижнему порогу 30 и неправильное значение поля value при отказе на запрос рецепта торта.
В улучшенном варианте исправился только ответ о разности C и A; две другие ошибки сохранились. Это изменение не связано непосредственно с давностью показаний и не доказывает пользу блокировки для основной метрики.
Локальные проверки блокировки давности пройдены. В улучшении изменён только флаг проверки давности, модель и агент не пересобирались.

В последнем запуске агента: 75 вызовов инструментов, 113 вызовов модели с учтёнными токенами. В улучшенном: 76 и 107 соответственно. Во всех четырёх замерах ошибок вызова системы и судьи не зафиксировано.

Неверный отказ по формату может быть семантически обоснованным: на рецепт торта система действительно отказалась, но value не равен контрактному значению «отказ». Разбор должен отделять ошибку формата от выдуманных данных.
